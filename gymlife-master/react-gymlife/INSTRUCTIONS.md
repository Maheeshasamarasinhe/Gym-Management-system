# React GymLife - Complete Website

## Quick Start

1. **Navigate to project directory:**
   ```bash
   cd c:\Users\ASUS\Downloads\gymlife-master\react-gymlife
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the application:**
   ```bash
   npm start
   ```

4. **Open browser:**
   Go to `http://localhost:3000`
